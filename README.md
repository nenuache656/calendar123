# Финансовый календарь с инфографикой

Статический сайт для GitHub Pages. Личный учёт доходов, расходов и бюджета с графиками.

## Возможности

- 📅 Месячный календарь с навигацией (вперёд/назад, кнопка "Сегодня")
- 💰 Доходы, расходы и переводы с категориями
- 📊 Инфографика (Chart.js):
  - Доходы vs Расходы (кольцевая диаграмма)
  - Расходы по категориям (круговая диаграмма)
  - Динамика доходов и расходов за 6 месяцев (столбчатая диаграмма)
- 📈 Карточки статистики: доходы, расходы, баланс, сбережения, динамика %
- 📋 Список событий текущего месяца
- 💾 Сохранение данных в локальном хранилище браузера (localStorage)
- 📤 Экспорт данных в JSON
- 🌗 Тёмная и светлая тема
- 📱 Адаптивная верстка (мобильные устройства)

## Как загрузить на GitHub Pages

1. Создайте новый репозиторий на GitHub (например, `finance-calendar`).
2. Загрузите в него все файлы из этого проекта (через веб-интерфейс GitHub или `git push`).
3. Перейдите в настройки репозитория: **Settings → Pages**.
4. В разделе **Build and deployment → Source** выберите ветку `main` (или `master`) и папку `/ (root)`.
5. Нажмите **Save**.
6. Через минуту сайт будет доступен по адресу:
   `https://<ваш-логин>.github.io/<имя-репозитория>/`

### Через терминал (если есть git)

```bash
git init
git add .
git commit -m "Initial commit: finance calendar"
git branch -M main
git remote add origin https://github.com/<логин>/<репозиторий>.git
git push -u origin main
```

Затем включите GitHub Pages в настройках репозитория, как указано выше.

## Данные и конфиденциальность

Все данные хранятся **только в вашем браузере** (localStorage). Никакие данные не отправляются на сервер. Если вы очистите данные браузера, события пропадут — поэтому рекомендуется периодически делать экспорт JSON через кнопку "Экспорт JSON".

## Технологии

- HTML5 + CSS3 (без фреймворков)
- Vanilla JavaScript
- [Chart.js](https://www.chartjs.org/) (через CDN) для графиков
